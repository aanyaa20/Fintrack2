# Landing Page Assets

This directory contains image assets for the FinTrak landing page.

## Required Images

Place the following images in this directory:

### Hero Section
- `dashboard-preview.png` - Main dashboard screenshot (1200x900px recommended)

### Features Section
- `feature-transactions.png` - Transaction recording interface (800x600px)
- `feature-analytics.png` - Analytics dashboard view (800x600px)
- `feature-reports.png` - Report generation interface (800x600px)
- `feature-receipt.png` - Receipt scanning feature (800x600px)

### How It Works Section
- `step-signup.png` - Account creation flow (800x500px)
- `step-record.png` - Transaction recording demo (800x500px)
- `step-analyze.png` - Analytics view demo (800x500px)

## Image Guidelines

- **Format**: PNG or JPG
- **Quality**: High resolution, optimized for web
- **Style**: Clean, professional screenshots or mockups
- **Consistency**: Maintain consistent styling across all images

## Fallback Behavior

If images are not found, the landing page will display placeholder SVG images with descriptive text. Replace these with actual screenshots for production.

## Creating Screenshots

1. Use actual FinTrak dashboard views when possible
2. Ensure sensitive data is removed or mocked
3. Use consistent browser/device frames if adding mockups
4. Optimize images before adding (use tools like TinyPNG or ImageOptim)
